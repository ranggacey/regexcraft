# RegexCraft 🛠️

Interactive regex tester built with React + TypeScript + Tailwind CSS v4.

## Features

- Live regex pattern matching with highlighted results
- Flag toggles (g, i, m, s, u, y)
- Match details with capture groups
- Copy regex pattern
- Dark mode UI

## Stack

- React 19 + TypeScript
- Vite 8
- Tailwind CSS v4
- No external runtime deps (zero regex libs — pure JS `RegExp`)

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
